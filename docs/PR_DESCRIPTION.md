Implements the Yc-Log-Sdk V1.0 Android logger in the existing SDK module and adds a native Sample app plus Java examples. App-first initialization is reused by Bluetooth SDK callers; a single file executor coordinates daily logs, retention, record-safe capped trimming, headers and ordered ZIP export. SDK runtime dependencies are limited to Kotlin stdlib.

Validation: Debug/Release APK and AAR builds, both Android test APK builds, 29 JVM tests (28 SDK + 1 Sample), and lint passed with 0 errors. Independent review found a header-marker parsing defect, fixed with an export/restart/header-update/trimming regression. Device tests were not run because adb lists no devices; AGP does not define Release unit tests by default. See README.md and docs/KNOWN_ISSUES.md for exact validation limits and two deferred minor test/header-input cases.
